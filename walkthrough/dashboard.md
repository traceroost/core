The sidebar gives you a compact live view. For the full experience, open the **editor panel dashboard** — a 5-tab interface, plus Help, Pricing, Settings and suggestion icons, that you can open alongside your code.

## Dashboard tabs

| Tab | What it shows |
| --- | --- |
| **Traces** | Trace list as a sortable table — start time, model, language (**Lang**, abbreviated, "+1" for a second language), change size (**Changes**: files and lines the agent edited), prompt, git outcome, signals, turns, duration, tokens, estimated cost, and, on a Claude or ChatGPT plan, **Plan limit** per row. Click a column header to sort (sorting returns to page 1); filter by agent, language, time range, prompt text, repo, git outcome, data source, or initiator — the agent pills and language list offer only what your traces contain. Click any row to expand in-place and drill into five sub-tabs: Overview (stat tiles, burn rate, and Insights), Waterfall (LLM and tool call timing), Flow (turn-to-tool graph), Tools (donut chart), and Files (modified files with inline diffs, a one-shot/retry-rate summary, and a git-outcome banner showing whether each file's changes were merged, committed, or are still uncommitted) |
| **Analytics** | Aggregate charts across all traces: per-agent breakdown (token totals, cache rates, one-shot rate, top tools), Plan Limits (Claude/ChatGPT plan windows), Outcome & Token Spend over time, Code Changes over time (agent-authored lines +/− and files changed), Estimated Cost (bar chart + daily total line, day-grouped cost table, model breakdown), Token Usage Per Trace, and Context Growth |
| **Advisor** | A ranked "How to spend less" list, plus project-scoped suggestions for improving your agent instruction file — detects hot files the agent rediscovers each trace, behavioral loop patterns, high turn counts, and open-ended prompt habits. Each suggestion includes ready-to-copy instruction text and an inquiry prompt to paste directly into your agent. Also includes an efficiency scatter plot and hot files table. Suggestions are per repo — for the open folder in VS Code (the standalone dashboard groups them by repo) — and Apply appends one to the instruction file you pick. |
| **Export** | Export recorded traces — full (includes prompt text) or redacted — as JSON, CSV, or Markdown, from the full SQLite trace history |
| **Import** | Preview and import traces from a previously exported TraceRoost JSON file |

The **Help** icon opens setup instructions, agent data shapes, the Insights and signal reference, MCP setup, and a glossary; the **$** icon shows the pricing tables behind every cost estimate; the **Make a suggestion** icon opens TraceRoost's public suggestion page in your browser (the link carries only the TraceRoost version and current tab); and the action log lists every command TraceRoost has run on your machine. Two more icons handle alerting and configuration without cluttering the tabs themselves:

- **Bell icon** — shows a badge when an alert threshold is currently triggered; click it for a status card with severity and detail per alert.
- **Gear icon** — opens a slide-in Settings panel with two collapsible sections: **Alerts** (configurable thresholds — context window size, turn count, error spike, active trace time, cache utilization, identical tool repeats, plan-limit windows, and daily cost across all agents) and **Automation** (automated prompts triggered when thresholds are crossed — Context Compaction, Loop Breaker, Error Cascade Stop, and Turn Limit Wrap-up). Also holds the OTEL/log ingestion toggles, the Configure OTEL button, and the MCP server toggle.

Use the **time range**, **agent filter**, and **text search** controls at the top to focus on what matters.
